**AUTOMATIC PET FOOD DISPENSER USING ARDUINO**

**1\. Aim**  
To design an automatic pet food dispenser using Arduino, an ultrasonic sensor and a servo motor.

**2\. Problem Statement**  
Manually feeding pets at regular intervals can be difficult when the owner is busy or away.

**3\. Proposed Solution**  
The ultrasonic sensor detects the presence of a pet near the dispenser. Arduino controls the servo motor to open the food outlet and dispense food automatically.

**4\. Components Required**  
Arduino  
Ultrasonic Sensor (HC-SR04)  
Servo Motor (SG90)  
Food container  
Breadboard  
Jumper wires  
Power supply

**5.circuit flow**  
The ultrasonic sensor detects the distance of the pet from the dispenser. When the pet comes within the set distance, Arduino activates the servo motor. The servo rotates and opens the food outlet, allowing food to fall into the bowl.

**6\. Procedure**  
Connect the ultrasonic sensor to Arduino.  
Connect the servo motor to the Arduino.  
Fix the servo motor to the food outlet.  
Upload the Arduino program.  
Fill the container with pet food.  
Test the system by bringing an object near the sensor.

**7\. Applications**  
Homes  
Pet shelters  
Veterinary clinics  
Animal care centres  
Smart pet-care systems

**8\. Advantages**  
Automatic feeding  
Reduces manual effort  
Simple and low-cost  
Easy to operate  
Provides convenient pet care

**9\. Result**  
The system successfully detects the pet and automatically dispenses food using the servo motor.

**10\. Conclusion**  
The automatic pet food dispenser provides a simple and convenient way to feed pets using Arduino-based automation.
